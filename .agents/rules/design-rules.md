# Reglas de Diseño e Identidad Visual

- **Paleta estricta:** Usar exclusivamente `#171317` (Negro elegante), `#E83E78` (Rosa principal), `#F5C8D9` (Rosa suave), `#FFF9F7` (Marfil), `#8C7C84` (Malva grisáceo) y `#FFFFFF` (Blanco).
- **Tipografías:** Usar `Cormorant Garamond` para títulos/encabezados (con énfasis opcional en cursiva `#E83E78`) y `DM Sans` para cuerpo, navegación, botones y formularios.
- **Mobile-First:** Diseñar y validar primero para pantallas móviles (`375px`) antes de ajustar escritorio.
- **Coherencia:** Mantener la misma estética elegante y minimalista tanto en la web pública como en el panel administrativo.
- **Estados completos:** Todo componente interactivo o asíncrono debe contemplar estados `loading`, `empty`, `error` y `focus-visible`.
- **Referencia:** Consultar `docs/BRAND_GUIDE.md` y `docs/DESIGN_SYSTEM.md` antes de implementar nuevos componentes.
